# Simulated transcript truth corpus v1

This hand-authored corpus is a tiny, deterministic analogue of a SIRV-style
mixture. It contains two annotated transcripts and two synthetic novel
transcripts with a novel splice acceptor. Each known/novel class has a
high-support/high-expression and a
low-support/low-expression member. Read records are exact genomic alignments, so
the truth is defined directly rather than generated by the Rust implementation.

CI runs junction clustering and unique assignment at zero-base junction
tolerance, then evaluates exact half-open exon structures. Reports include
precision, recall, F1, expected/observed abundance, and absolute abundance error
for all transcripts, known versus novel, support bins, expression bins, and each
class/bin combination.

## External evaluation compatibility

`truth_index.tsv` records transcript/gene IDs, known versus novel status,
simulated read abundance, and expression/support strata. It deliberately does
not assign an external structural classification. The integration test validates
that the predictions can be represented as:

- SQANTI3/LRGASP exon-based GTF (`models.gtf`),
- LRGASP `read_model_map.tsv` with `read_id` and `transcript_id`, and
- LRGASP `expression.tsv` with an `ID` column and TPM replicate columns.

No SQANTI-SIM, LRGASP, SIRV, genome, or read files are redistributed. This avoids
unclear data licensing and keeps normal CI small. The schema choices follow the
GPL-3.0 SQANTI-SIM project documentation and the MIT-licensed LRGASP submission
format documentation; only our synthetic records and original test code are
checked in.

Primary format references:

- <https://github.com/ConesaLab/SQANTI-SIM>
- <https://github.com/LRGASP/lrgasp-submissions/blob/master/docs/model-format.md>
- <https://github.com/LRGASP/lrgasp-submissions/blob/master/docs/read_model_map_format.md>
- <https://github.com/LRGASP/lrgasp-submissions/blob/master/docs/expression_matrix_format.md>

`SHA256SUMS` freezes every truth/input/expected artifact consumed by CI.
