# TrackCluster 0.1.8 independent parity corpus

This directory is intentionally separate from `tests/golden/`. The latter is
generated by the Rust implementation; this corpus was generated by the legacy
Python TrackCluster implementation and is an independent behavioral oracle.

## Provenance

- Tool: Python TrackCluster `0.1.8` (`trackcluster.__version__`).
- Local source snapshot used: `../trackclusterRust`; its installed metadata
  reports version `0.1.8` and GPL-2.0 licensing. No legacy source or third-party
  biological data is copied here. That directory has no Git metadata, so
  `LEGACY_SOURCE_SHA256SUMS` identifies the exact imported Python modules and
  package metadata; the generator refuses a different snapshot.
- Inputs: hand-authored, synthetic bigGenePred records in `inputs/`. They test a
  reference-compatible 5-prime truncation and a transcript with a novel junction
  chain.
- Generation command, run from this repository root:

  ```sh
  TRACKCLUSTER_LEGACY_ROOT=../trackclusterRust \
    python3 tests/independent/legacy_trackcluster_0_1_8/generate_expected.py
  ```

- Legacy algorithm invoked: `trackcluster.clusterj.flow_junction_cluster`.

`SHA256SUMS` freezes the input, generator, source-provenance manifest, and
expected-output bytes. The normal, non-ignored integration test verifies those
hashes before comparing a current Rust run.

## Deliberate comparison boundary

The oracle stores chromosome, strand, half-open exon coordinates, known/novel
status, and represented read IDs. It deliberately does not compare generated
novel isoform IDs, BED display fields, or name2 serialization:

- TC-012 is allowed to replace representative-read names with stable structured
  IDs without weakening this test.
- Python omits the representative read from its own `subread` set; the generator
  restores it when projecting represented molecules.
- Rust may serialize support in name2 and emit a separate mapping TSV, while
  Python 0.1.8 serializes merged subread names in name2.

Any change to transcript structure or represented-read membership still fails CI
until `expected_structures.tsv` and its checksum are explicitly reviewed.
